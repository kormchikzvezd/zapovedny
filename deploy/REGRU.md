# Запуск на reg.ru — обычный виртуальный хостинг

Подходит для Reg.ru, Timeweb, Beget и любого shared-хостинга с PHP 8.
Node.js на сервере не нужен.

## Что уже сделано и проверено

Сайт собран в статику и лежит в папке `dist/upload-zapovedny` — 44 файла, 6,6 МБ.
Проверено локально на PHP 8.4: главная отдаётся, все 19 изображений и шрифты на месте,
форма отправляет заявку в базу, проданный дом сервер не принимает — 20 проверок из 20.

## Шаг 1. Привязать домен к хостингу

Сейчас `zapovedny-dom.ru` показывает парковочную страницу reg.ru — это значит,
что домен не привязан к сайту.

1. Откройте панель reg.ru.
2. **Домены и поддомены → Управление → zapovedny-dom.ru**.
3. Выберите ваш хостинг в качестве площадки.
4. Убедитесь, что в панели хостинга домен тоже добавлен: **Сайты и домены → Ваши домены**.

## Шаг 2. Загрузить файлы

Возьмите папку `dist/upload-zapovedny` — её нужно положить в корень сайта.
Способ 1: распакуйте архив и загрузите через файловый менеджер панели.
Способ 2: загрузите по FTP на адрес, который покажет панель.

**Важно:** загружать нужно содержимое папки, а не саму папку.
Если архив называется `upload-zapovedny.zip`, то после распаковки в корне сайта
должны лежать `index.html`, `api/`, `images/`, `_next/`, `fonts/`, `data/`.

## Шаг 3. Права на папку data

Папка `data` должна быть доступна для записи, иначе база не создастся.

- Права на папку `data`: **770**
- Если заявки не сохраняются, попробуйте **755**

## Шаг 4. Настроить уведомления в Telegram

1. Откройте Telegram, найдите **@BotFather**, отправьте `/newbot`, получите токен.
2. Скопируйте `api/config.example.php` в `api/config.php`.
3. Впишите в `config.php`:

```
TELEGRAM_BOT_TOKEN = '123456789:AAExampleToken'
TELEGRAM_CHAT_ID = '987654321'
```

Chat ID узнать: напишите боту любое сообщение и откройте в браузере
`https://api.telegram.org/bot<ТОКЕН>/getUpdates` — найдите `"chat":{"id":...}`.

Файл `config.php` закрыт от посетителей через `.htaccess` — токен не утечёт.

## Шаг 5. Включить SSL

В панели reg.ru: **Сайты и домены → SSL-сертификат → Бесплатный (Let's Encrypt)**.
Продлевается автоматически.

## Проверка после загрузки

| Что | Как проверить | Норма |
| --- | --- | --- |
| Главная | Открыть `https://zapovedny-dom.ru/` | Страница с каталогом домов |
| Фотографии | Правая кнопка → открыть картинку в новой вкладке | Картинка, а не ошибка |
| Телефон | Нажать кнопку «Позвонить» на телефоне | Открывает `+7 923 425-68-36` |

Если приходит `{"error":"not_configured"}` — не создан `api/config.php`.
Если форма показывает ошибку — откр��йте журнал ошибок хостинга в панели.

## Управление домами — самое частое

Откройте `data/homes.json` в редакторе панели. Найдите нужный адрес и поменяйте статус:

```json
{ "id": "8/1", ..., "status": "sold" }
```

Статусы:

| Статус | Показывается на сайте | Когда ставить |
| --- | --- | --- |
| `available` | Да | Дом в продаже |
| `reserved` | Нет | Забронирован, ждём сделку |
| `sold` | Нет | Продан |
| `preparing` | Нет | Готовится к продаже |

Сохраните файл — и всё. **Пересборка не нужна:** сервер читает этот файл при
каждом запросе. Проданный дом сразу исчезнет с сайта, и заявку на него
отправить больше не получится — проверка идёт на сервере.

## Посмотреть заявки

**Способ 1.** В панели хостинга откройте phpMyAdmin или файловый менеджер —
база `data/leads.db`.

**Способ 2.** Спросите хостера про SSH, затем:

```bash
sqlite3 ~/zapovedny-dom.ru/data/leads.db \
  "select created_at, name, phone, preferred_channel, homes from leads order by id desc limit 20;"
```

## Резервные копии

На shared-хостинге автоматический бэкап настроить сложнее. Самое простое —
раз в неделю скачивать файл `data/leads.db` через файловый менеджер.

## Если что-то пошло не так

| Симптом | Причина | Что делать |
| --- | --- | --- |
| Парковочная страница reg.ru | Домен не привязан к хостингу | Шаг 1 |
| Открылся список файлов | Нет `index.html` в корне | Загрузить содержимое папки |
| Фото не открываются | Загружена папка внутрь другой | Загрузить содержимое, не папку |
| `{"error":"not_configured"}` | Нет `api/config.php` | Шаг 4 |
| Заявки не сохраняются | Нет прав на `data` | Шаг 3 |
| Сайт без стилей | Не загрузилась папка `_next` | Загрузить заново целиком |
